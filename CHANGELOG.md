# Changelog

Notable changes to FinCalc are recorded here.

## 1.0.0 — 2026-11-19

- Initial Android release with interest, EMI, Indian tax, currency, percentage and discount tools.
- Added Material 3 light/dark themes, local settings and adaptive launcher icon.
- Added keyless exchange reference rates with an explicitly labeled offline cache.
- Added calculation unit tests and GitHub project documentation.
